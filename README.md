# habit_tracker_system Flow

This project defines a declarative CrewAI Flow in `src/habit_tracker_system/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/habit_tracker_system/flow.yaml` to change the flow. Add reusable crews under `src/habit_tracker_system/crews/`, custom Python tools under `src/habit_tracker_system/tools/`, and shared knowledge files under `src/habit_tracker_system/knowledge/`.
